# ublock-filter-lists

A collection of uBlock Origin filters. They're mostly related to YouTube and TUM-Webpages.

The following filter lists are available:

## Block AI Slop

A filter list for blocking websites that are entirely AI generated, for example DeepWiki

You can install this filter list by going to your `uBlock-Settings > Filter lists > Import` and pasting the following URL:

```
https://raw.githubusercontent.com/Joel-dev-IMP/ublock-filter-lists/refs/heads/main/ai-slop.txt
```

## Block YouTube AI synchronizations

Remove videos with AI-generated translations from your home feed and next video suggestions on YouTube.
This is done by searching for the badge "Auto-dubbed".

You can install this filter list by going to your `uBlock-Settings > Filter lists > Import` and pasting the following URL:

```
https://raw.githubusercontent.com/Joel-dev-IMP/ublock-filter-lists/refs/heads/main/youtube-ai-synced.txt
```

## Hide Short-Form content

Based on https://github.com/gijsdev/ublock-hide-yt-shorts, with added filters for TikTok (blocks TikTok entirely).
